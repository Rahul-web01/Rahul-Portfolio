## ⚙️ Getting Started

Clone and run this portfolio locally:

```bash
# Clone the repository
git clone https://github.com/Rahul-web01/Rahul-Portfolio.git
cd Rahul-Portfolio

# If it's a Jekyll / GitHub Pages site
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000` in your browser.

> 📝 Update `_config.yml` with your site title, description, and social links before deploying.
